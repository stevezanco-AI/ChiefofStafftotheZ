# Framework: AI Tool Evaluation

Use this when evaluating any AI tool, platform, or vendor for your team or personal use.

## Evaluation Criteria

| Criterion | Weight | Score (1-5) | Notes |
|-----------|--------|-------------|-------|
| Solves a real problem | 30% | | |
| Ease of adoption for team | 20% | | |
| Integration with existing tools | 15% | | |
| Cost vs. ROI | 20% | | |
| Data security / privacy | 15% | | |

## Key Questions to Answer

1. **Problem fit:** What specific problem does this solve? Is it a top-10 problem?
2. **Adoption risk:** Will my team actually use it? What's the change management cost?
3. **Dependency risk:** What happens if this vendor disappears or raises prices?
4. **Measurement:** How will I know if it's working in 30 / 60 / 90 days?
5. **Alternatives:** What's the next-best option and why is this better?

## Decision Threshold

- Score ≥ 3.5 weighted average → Pilot with 1-2 reps for 30 days
- Score < 3.5 → Revisit in next quarter unless a top-10 problem
- Any score of 1 in security → Do not proceed
